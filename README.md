# SafetyALFRED
Code for SafetyALFRED paper published at the 2026 Findings of the Association for Computational Linguistics.

### Making a Conda Environment 

We recommend using [conda](https://www.anaconda.com/docs/getting-started/miniconda/main) and creating a virtual environment.

```
conda create --name SafetyALFRED python==3.7.16

conda activate SafetyALFRED

pip install -r requirements.txt
```

### Genearating and Rendering SafetyALFRED Trajectories

**Step 1:** Download Fast Downward Planner from their [Github Repository](https://github.com/aibasel/downward/releases/tag/release-24.06.1)

**Step 2** Place the uncompressed folder at SafetyALFRED/src/pipeline_bundle/alfred_git/alfred/data/DANLI/pddl and rename folder to fast-downward-24.06.1n

**Step 3:** Follow Fast Downward build instructions at [BUILD.md](https://github.com/aibasel/downward/blob/main/BUILD.md)

**Step 4:** Set environment variables below

```
export ET_ROOT="src/pipeline_bundle/E.T."
export ET_LOGS=$ET_ROOT/logs
export ET_DATA=$ET_ROOT/data
export PYTHONPATH=$PYTHONPATH:$ET_ROOT
```

**Step 5:** Run pipeline_pddl_to_video_thor5.py Python script at src/pipeline_bundle/alfred/gen/pipeline_pddl_to_video_thor5.py for the traj_data.json argument you can use either the original ALFRED trajectories in SafetyALFRED/pddl_trajs or one of the safety_trajectories generated by the SafetyALFRED authors in SafetyALFRED/safety_trajs. 

**NOTE:** Not all of trajectories in safety_trajs will work as these were rendered in batch using SafetyALFRED/src/pipeline_bundle/alfred/gen/test_pipeline_safety_trajs.py and then the authors manually watched the successfully rendered videos and filtered them. The trajectories used to generate the SafetyALFRED Trajectories can be found within the converted_trajectory directories within the SafetyALFREDTrajectories directory which can be download from [Huggingface](https://huggingface.co/datasets/Diginyx/SafetyALFRED) (e.g. SafetyALFREDTrajectories/appliance_misuse/pick_cool_then_place_in_recep/trial_T20190906_192817_654400/converted_trajectory/traj_data.json)
```
python pipeline_pddl_to_video_thor5.py --traj_json {/path/to/traj_data.json} --output_dir /tmp/test --use_teleport --no_time_delays --no_smooth_nav --clear_microwave_objects --clear_sink_objects
```
